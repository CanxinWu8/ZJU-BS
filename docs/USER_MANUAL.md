# 《B/S体系软件设计》企业智能协同审批系统 —— 使用手册

## 1. 系统运行环境与容器化一键部署

### 1.1 软硬件环境要求
- **操作系统**：Linux / Windows (WSL 2) / macOS
- **容器环境**：Docker Engine $\ge$ 24.0，Docker Compose $\ge$ v2.20
- **浏览器要求**：Chrome / Edge / Safari 最新版，支持桌面端宽屏及手机端响应式触控视图

### 1.2 Docker Compose 一键启动步骤
本系统采用 Docker Compose 编排，包含 `approval-mysql`（MySQL 8.0 数据库）、`approval-backend`（FastAPI 后端服务）与 `approval-frontend`（Vue 3 + Nginx 前端网关）三个容器。

```bash
# 1. 进入项目根目录
cd /home/wucanxin/BS

# 2. 构建镜像并后台启动全部容器
docker compose up -d --build

# 3. 检查容器健康状态（确保 3 个服务均为 Up / healthy）
docker compose ps
```

### 1.3 系统访问入口
- Web 应用主入口（桌面端 & 手机端自适应）：http://localhost:8080

- 后端 OpenAPI (Swagger) 接口文档：http://localhost:8000/docs

- 数据持久化验证命令：执行 docker compose restart 重启服务后，所有业务数据、审批历史及上传票据均保存在挂载卷 ./mysql_data 与 ./storage/attachments 中，不会丢失。

## 3. 核心业务功能操作指南

### 3.1 注册、登录与角色授权

1. 新员工注册：在登录页切换到“新员工注册”标签，填写唯一用户名、姓名、唯一邮箱、选择申请加入的部门并输入至少 8 位密码。注册成功后默认仅具普通员工权限，无法自行指定高权限角色。
2. 管理员确认与授权：使用 admin 登录，点击左侧导航【⚙️ 系统管理后台】->【👥 用户与多角色授权】，可修改用户所属部门、激活状态，并为用户勾选兼任角色（如同时勾选“部门负责人”与“财务审批人”），保存后自动写入管理审计日志。

### 3.2 发起三类固定业务申请

点击左侧导航【✍️ 发起新申请】（或工作台顶部快捷按钮）：

1. 采购审批流程：
  - 填写申请标题、期望到货日期、所属项目、预算上限及采购原因。   
  - 采购明细：支持动态新增/删除，正式提交时至少包含 2 条明细，系统实时并在服务端自动重算小计与总金额。   
  - 供应商比价：默认需录入至少 2 家供应商报价并上传报价截图/链接。若勾选“单一来源采购例外”，则允许仅填 1 家但必须填写详细的【单一来源说明】。   
  - 非最低价校验：当勾选的“拟选供应商”报价高于最低报价时，界面将自动弹出必填项【未选最低价理由】

2. 差旅申请流程：
  - 填写出发地、目的地、起止日期（结束日期不得早于开始日期）、交通方式、同行人员、费用预算（不得为负数）及出差目的。
  - 系统按自然日口径（$\text{结束日期} - \text{开始日期} + 1$）自动计算并展示出差天数。   
  - 差旅申请获批（APPROVED）后，自动进入申请人名下的“可关联前置申请池”。

3. 费用报销审批流程：
  - 前置关联：可在顶部下拉框中选择本人已获批的差旅或采购申请进行关联（详情页将联动展示原差旅/采购信息），也可留空作为独立日常报销。
  - 费用明细：支持交通、住宿、餐饮、办公、其他五类明细动态增删，提交时至少需 3 条有效明细（金额必须 > 0）。
  - 票据上传与无票例外：每条明细默认需上传至少 1 份票据（支持 JPEG/PNG/PDF，单文件 ≤ 10MB）。若确无发票，需勾选“无票支出例外”并填写原因，财务审核界面将对其进行红色高亮提示。   
  - 跨单重复发票预警：上传发票或输入发票号时，系统自动计算文件 SHA-256 哈希并检索历史报销库；若检测到重复使用，将立即弹出红色跨单重复预警。

### 3.3 管理员配置自定义审批流程

1. 使用 admin 登录，进入【⚙️ 系统管理后台】->【🧩 自定义审批流程模板引擎】。

2. 点击【+ 创建/编辑自定义审批模板】，无需修改任何代码即可配置新流程（如“员工请假审批”、“企业公章使用审批”、“研发设备借用审批”）：  
  - 动态表单字段：支持添加单行文本、多行文本、数字/金额、日期、单选按钮组及附件字段，并设置是否必填。
  - 顺序审批节点：支持配置不少于 2 个顺序节点，可通过“↑上移 / ↓下移”调整顺序，每个节点支持配置“申请人部门负责人”、“按角色解析”或“指定具体用户”。

3. 点击【校验并发布新版本】，服务端校验字段标识唯一、节点完整无环且审批人可解析后，自动生成新版本（如 v1 -> v2），已有历史申请单保留提交当时的快照不受影响。

### 3.4 审批流转、撤回、催办与委托操作

- 逐级顺序审批：当前节点审批人在【⏰ 我的待办】中进入详情页，可点击【✅ 批准通过】或【❌ 驳回申请（必填理由）】。前一节点通过后自动激活下一节点并发送实时通知。   
- 撤回与复制重提：申请人在申请处于“审批中”时可点击【↩️ 撤回申请】（带二次确认弹窗）；对于“已驳回”或“已撤回”的申请，点击【📋 复制修改并重新提交】可一键生成关联原单的新草稿。   
- 一键催办：申请人可在审批中详情页点击【⚡ 一键催办当前节点】，向当前审批人发送高优先级提醒并写入审批日志。   
- 审批委托：审批人可在【📊 工作台与统计】点击【🤝 审批委托设置】，指定时间段内的代审同事，系统将自动转交待办并记录委托留痕。 

### 3.5 移动端适配与实时/后台提醒使用说明

- 手机端触控体验：使用手机浏览器访问或开启浏览器开发者工具切换至手机视图（宽度 < 768 px），系统自动隐藏左侧边栏、启用底部固定触控导航栏，并将复杂表格自动转换为无横向滚动的卡片列表；点击发票上传可直接调用手机相机拍照上传。
- 实时与后台提醒：页面打开时通过 SSE 实时流免刷新自动弹出新待办与审批结果通知条（点击通知直接跳转对应申请详情）；首次登录允许浏览器通知权限后，Service Worker 将注册 WebPush / 系统级通知，即使页面处于后台也可收到系统通知栏提醒
